# Deployment outcomes

- [ ] **Preserve and deploy the existing dashboard:** Preserve and deploy the existing React traffic dashboard as the public website interface. Preserve its traffic-map visualization, existing dashboard data contract, and submitted SUMO city network, routes, and configuration. Use same-origin API and WebSocket requests in the published site.
- [ ] **Operate the real trained SUMO/PPO simulation:** Preserve and run the uploaded SUMO city scenario with the existing trained PPO agent. Operate a persistent FastAPI/TraCI backend that keeps the PPO-controlled simulation running continuously. Control A1, B0, B1, B2, and C1 with the existing five-second decision interval while preserving programmed yellow/all-red transitions. Stream live vehicle positions/movement, all nine signal states, emissions, and traffic-performance metrics from that actual PPO-controlled SUMO instance to the dashboard over WebSocket.
- [ ] **Keep public access read-only:** Provide public read-only access to the live simulation. Visitors can view its telemetry but cannot pause it, manually step it, or change its active controller. Omit mutation controls from the production dashboard and reject production pause, resume, step, and mode-change API requests; local development may retain its controls.
- [ ] **Publish the comparison report:** Include the existing baseline-versus-PPO evaluation report in the public website, retaining its measured waiting-time, total CO₂, queue, and throughput comparison and the stated seed-level regression/trade-off caveat.
- [ ] **Permanently deploy the whole product:** Deploy the frontend, persistent simulation backend, trained model/inference weights, and existing SUMO scenario using the user-authorized WebDev Reserved Hosting (`always_on`) setting. Use the platform's hosting confirmation workflow. Claim completion only after publication succeeds and observed hosting state confirms `always_on`; if a build, residency, or resource limit blocks the real live site, report the concrete blocker instead of silently substituting a static-only website.
